# MediPredict: Machine Learning-Based Healthcare Analytics and Disease Prediction Platform

## Project Overview
This is an individual project developed as part of the 2nd Year Project Implementation Phase at VSB Engineering College. The platform aims to analyze patient health data and predict potential diseases using Machine Learning algorithms.

## Project Details (Week 1 Schedule)
* **Project Title:** MediPredict: Machine Learning-Based Healthcare Analytics and Disease Prediction Platform
* **Problem Statement:** Early detection of chronic diseases is critical but often delayed due to manual analysis of complex medical reports. This project uses AI/ML to predict potential health risks based on patient metrics (e.g., blood pressure, glucose levels, age).
* **Core Modules:** 
  1. Recruiter/Admin Login Module
  2. Patient Data Input & Analytics Dashboard
  3. ML Prediction Engine
* **Tech Stack:** React.js (Frontend), Java Spring Boot (Backend), MySQL (Database).
